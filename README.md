# 卫戍协议伤害计算器

静态单页工具，针对《卫戍协议·规程》序列Ⅰ。内置该版本干员、敌人、装备、盟约及关底 Boss 档案，以及单人规程等级20和联机终极模拟的逐回合系数。档案来自 Stronghold-Protocol 的 `act3autochess-v3_1` 客户端数据整理；原始干员与敌人字段随 `dist/archive.js` 离线提供。

选择干员后，默认生成三组方案：方案一为初始形态且全空，方案二为初始形态且自身盟约各 50 层一阶，方案三为精锐形态且自身盟约各 100 层二阶。每组可独立改动形态、盟约与装备。技能在顶部统一选择，但每组使用所选形态对应的技能等级与数值。每组最多两件装备；转职需变形同构体和对应盟约道具，占满两格。

敌人先按普通、精锐、领袖或关底 Boss 分类，再按名称或编号搜索。关底 Boss 使用 `bosses.json` 的独立档案与共享生命池，不套用普通敌人的回合生命倍率；两种模式的档案基础血池以各自 `bloodDataDict` 为准；若实战血量不同，可用实际生命值输入框覆盖。普通敌人的逐回合生命倍率取自沿用上一季层数安排的推算，当前赛季尚未实测确认。可在顶部输入敌人的实际生命值覆盖推算。结果显示技能伤害、普攻伤害、持续伤害、循环 DPS 和预计击杀时间。预计击杀时间按“目标生命值 ÷ 循环 DPS”估算，仅适合比较配置；首领多阶段、无敌、伤害减免、其他玩家输出等需另行考虑。页面下方提供所用形态、敌人和 Boss 的档案，以及各组计算过程。

运行：直接用浏览器打开 `dist/index.html`；也可在 `dist/` 中执行 `python3 -m http.server 8000`。档案及计算无需联网。完整档案的展示不等于全部特殊机制均已加入伤害计算；复杂技能与敌人能力仍需按页面提示调整或另行建模。
